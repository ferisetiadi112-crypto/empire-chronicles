# Game Flow

## Volume 1

1. Launch Empire Chronicles.
2. Load or create a local world.
3. Select the player's modern country.
4. Enter the Home Country Map.
5. Manage population, settlements, economy, infrastructure and government.
6. Open the World Map for diplomacy, trade, investment and international events.
7. Advance simulation time.
8. Save locally.

## Simulation clock

The simulation uses a discrete game clock.

- 1 game day = 10 real minutes
- 1 game week = 70 real minutes
- 1 game month = 5 real hours
- 1 game year ≈ 60 real hours

The exact clock implementation will be connected to the 0 A.D. simulation timer rather than the renderer frame rate.
